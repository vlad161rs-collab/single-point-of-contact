## ⚠️ ВАЖНО про медиа файлы:

**На Heroku файловая система эфемерна!**

Это означает:
- Медиа файлы (картинки, аудио, видео) **будут потеряны** при перезапуске приложения
- Это **не подходит для продакшена**

### Решение для продакшена:

Используйте облачное хранилище:
- **Cloudinary** (рекомендуется - самый простой)
- AWS S3
- Google Cloud Storage

См. инструкцию в `FIX_ISSUES.md` для настройки Cloudinary.
